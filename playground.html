아이들나라 놀이터 비공개 테스트 개인정보처리방침

적용 앱: 아이들나라 놀이터 (com.inara.playground)
운영: U+tv 아이들나라
문의·개인정보 요청: inara@uplus.co.kr
시행·최종 수정: 2026-11-06
테스트 데이터 보유기간: 서비스 테스트 종료 시까지. 종료 일정은 별도 안내합니다.

이 방침은 아이들나라 놀이터와 연결 페이지에 적용됩니다. 동물 합치기·라떼 퀴즈쇼의 기존 방침과 달리, 놀이터는 AI 생성 및 서버 저장·분석 기능을 사용합니다. 다음 항목을 보호자와 함께 확인해 주세요.

1. 처리하는 정보와 목적

  • AI 글·그림·낭독·대화: 선택하거나 입력한 주제, 음성 입력 및 인식 결과, 대화 문맥, 연령대, 인형 모습과 생성 요청을 Google의 Firebase AI Logic/Gemini 서비스로 전송하여 동화·그림·음성 응답을 생성합니다. 음성 입력 경로에서는 외부 음성 인식·AI 서비스가 사용될 수 있으며 기기 내 처리만으로 한정되지 않습니다. 음성을 쓰지 않고 리모컨으로 주제를 선택할 수 있습니다.
  • 동화 서버 저장: 만든 동화의 본문·삽화·그림 프롬프트·연령대·생성 시각·앱 버전·생성 모델 정보 등을 Firebase Firestore와 Cloud Storage에 자동 업로드합니다. 반짝 옷장의 인형 사진·옷차림 설정도 포함될 수 있습니다. 익명 사용자 식별값으로 설치와 자료를 연결합니다. 낭독 파일은 기기에 저장하며, 동화 업로드는 이용 분석 설정과 별개입니다.
  • 프로필·기기 저장: 입력한 이름/별칭, 연령대, 관심사, 동화·인형 사진, 게임 진행, 입장권·놀이 시간, 미션 및 환경 설정을 기기에 저장하여 활동과 재생 기능을 제공합니다. AI 문맥에 포함된 입력 정보는 생성 요청에 사용될 수 있습니다.
  • 순위·의견: 익명 식별값과 게임 점수·주차 등 순위 기록, 선택형 의견과 앱·기기 정보·제출 시각 등을 Firebase에 저장하여 순위 제공과 테스트 개선에 사용합니다.
  • 이용 분석: Google Analytics for Firebase로 이용 이벤트·활동 시간·앱/기기 정보·설치 식별값 등을 분석합니다. 현재 테스트 버전은 이용 분석이 기본 켜짐이며 보호자 메뉴에서 끌 수 있습니다. 광고 개인화 용도로 동의를 부여하지 않습니다. SDK는 통신·보안 및 대략적인 지역 파악 과정에서 IP 주소를 처리할 수 있습니다.
  • 인증·보안·원격 설정: Firebase 익명 인증, App Check와 Remote Config가 설치·앱·기기 및 요청 관련 정보를 처리하여 서버 자료 접근, 오용 방지, 허용 버전 확인을 수행합니다. 이용자가 이메일 계정이나 결제 정보를 등록하는 절차는 없습니다.
  • 휴대폰 2인 연결: 연결 페이지 및 WebRTC 연결을 위해 임시 방 코드, 연결 설정 정보와 게임 조작 신호를 처리합니다. 연결 서비스는 네트워크 주소 등 통신 정보를 처리할 수 있습니다. 앱 안의 ‘사진찍기’는 꾸민 인형 화면 저장이며 실제 얼굴 촬영 기능이 아닙니다.

2. 보유기간과 파기

운영자가 관리하는 비공개 서비스 테스트 자료(서버 동화·의견·순위·분석 자료)는 서비스 테스트 종료 시까지 보유하고 종료 후 삭제합니다. 테스트 종료일은 별도 공지합니다. 보호자가 그 전에 삭제를 요청할 수 있습니다. 기기 자료는 앱 기능으로 삭제하거나 기기 설정에서 앱 데이터를 삭제할 때까지 보관될 수 있습니다.

기기 책장에서 동화를 삭제하거나 앱을 삭제해도 이미 업로드된 서버 사본이 자동으로 삭제되지는 않습니다. 서버 자료 파기는 운영자가 저장소와 관리 콘솔에서 수행합니다. Google이 서비스 제공·보안·오용 방지 등을 위해 별도로 처리하는 자료의 보유·삭제 절차는 해당 제공자의 정책과 계약에 따릅니다. 불필요해진 자료는 복구하기 어려운 방식으로 삭제하고, 법령에 따른 별도 보관 의무가 있으면 해당 범위와 기간만 구분하여 처리합니다.

3. 개인정보·서버 자료 삭제 요청

보호자는 inara@uplus.co.kr로 ‘아이들나라 놀이터 테스트 자료 삭제 요청’을 보내 열람·정정·삭제·처리 중지를 요청할 수 있습니다. 앱 이름·버전, 요청 대상(동화·순위·의견 등), 동화 제목과 대략적인 생성 시각 등 자료를 찾는 데 필요한 최소한의 정보만 알려주세요. 소유 확인과 식별에 추가 정보가 필요한 경우 별도로 안내하며, 비밀번호·주민등록번호 등은 요청하지 않습니다.

확인된 요청 범위의 Firebase 동화 문서·삽화·인형 사진 및 관련 자료를 삭제하고 처리 결과를 안내합니다. 요청 대상과 연결된 분석 식별값을 확인할 수 있는 경우 분석 자료 삭제도 함께 처리합니다. 다른 이용자의 자료나 신원을 확인할 수 없는 자료를 임의로 삭제하지 않습니다.

4. 외부 처리·국외 처리 안내

Google의 Firebase/Google Cloud 및 Google Analytics 서비스를 사용합니다. Google LLC 및 해당 서비스의 계약상 Google 계열사·하위 처리자가 위 항목을 서비스 제공, 저장, 생성, 분석, 인증 및 보안 목적으로 처리할 수 있습니다. 서비스 이용·생성·동기화·분석 요청 시 암호화된 네트워크 통신을 통해 전송합니다.

  • 동화 저장 위치: 현재 Firestore 데이터베이스와 Cloud Storage 버킷은 서울(asia-northeast3)에 설정되어 있습니다. 이 위치가 모든 인증·AI·분석 처리의 국내 한정을 뜻하지는 않습니다.
  • 국외 처리: Firebase Authentication은 미국에서 처리되며, Gemini Developer API와 위치를 선택하지 않는 Firebase·분석 기능은 미국을 포함한 Google 또는 처리자의 시설이 있는 국가에서 처리될 수 있습니다. 국가는 제품과 처리 경로에 따라 달라집니다. Vertex 경로의 모델 접근 리전과 실제 전체 처리 범위도 같다고 단정하지 않습니다.
  • 외부 제공자 안내: Firebase 개인정보·처리 정보, 제품별 위치 안내, Firebase 데이터 처리 조건, Google Cloud 하위 처리자, Google 데이터센터 국가·위치, Gemini API 처리 조건, Google Analytics 데이터 보호 안내에서 범위를 확인할 수 있습니다.

AI·서버 저장에 필요한 처리를 원하지 않으면 해당 온라인 기능을 이용하지 않고 보호자 메뉴에서 분석을 끌 수 있습니다. 필요한 처리가 제한되면 AI 생성·대화·업로드·순위·휴대폰 연결 기능 일부를 제공하기 어려울 수 있습니다. 별도 동의가 필요한 경우에는 해당 동의 절차를 통해 안내하며, 이 웹페이지를 읽는 행위 자체를 동의로 보지 않습니다.

5. 아동과 보호자

보호자는 어린이가 실명·주소·연락처·학교 등 개인정보를 입력하거나 말하지 않도록 도와주세요. 어린이의 입력에 이러한 정보가 들어가면 생성 요청이나 동화 본문에 포함되어 처리될 수 있습니다. 기기 설정에서 마이크 권한을 철회할 수 있으며, 보호자 메뉴에서 이용 분석을 변경할 수 있습니다. AI가 만든 내용은 보호자가 함께 확인해 주세요.

6. 보호 조치와 변경 안내

자료 전송 시 HTTPS를 사용하고 Firebase 접근 규칙과 앱 검증, 운영 권한으로 접근을 제한합니다. 처리 항목·목적·기간이 바뀌면 이 페이지의 수정일과 앱/스토어 안내를 갱신합니다. 개인정보 문의·침해 신고·AI 생성물 문제 신고는 inara@uplus.co.kr로 보내실 수 있습니다. 이 메일 안내가 앱 안의 신고 기능을 대신한다는 의미는 아닙니다.
